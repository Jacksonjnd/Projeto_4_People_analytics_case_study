# 📘 Ebook | Case de People Analytics

Este projeto apresenta um **ebook desenvolvido a partir de um case real de People Analytics (Programa de desenvolvimento)**, com foco em transformar dados de pessoas em uma narrativa clara, visual e estratégica.

Por questões de confidencialidade, **o nome da empresa, do programa e qualquer informação que pudesse identificar a organização foram anonimizados**.

O objetivo do material foi ir além de uma apresentação tradicional de resultados e transformar a análise em um **case de portfólio**, combinando dados, storytelling e design editorial.

---

## 🎯 Objetivo do ebook

O estudo acompanha um grupo de **32 participantes ao longo de 15 meses**, analisando temas como:

- engajamento;
- permanência e desligamento;
- gênero;
- origem da indicação;
- reconhecimento;
- promoções e méritos;
- performance.

A proposta foi mostrar não apenas os números, mas também:

- o que cada resultado pode indicar;
- quais cuidados devem ser considerados na interpretação;
- como transformar os achados em ações práticas;
- como dados de People Analytics podem apoiar decisões de negócio.

---

## 🔒 Anonimização dos dados

Este material foi construído a partir de um contexto real.

Para preservar a confidencialidade:

- o nome da empresa foi removido;
- o nome do programa foi substituído;
- nomes de iniciativas internas foram alterados;
- nenhuma informação individual dos participantes é apresentada.

Os dados foram utilizados exclusivamente para demonstrar a construção analítica e a forma de comunicar os resultados.

---

## 🎨 Design editorial

O ebook foi desenvolvido com uma proposta visual inspirada em **relatórios editoriais, estudos de caso e publicações digitais premium**.

Entre as principais técnicas utilizadas estão:

### Hierarquia visual

Uso de diferentes níveis de destaque para facilitar a leitura:

- títulos grandes;
- subtítulos;
- números de capítulo;
- frases de impacto;
- indicadores em destaque.

Isso permite que o leitor entenda rapidamente o assunto de cada página antes mesmo de ler todo o conteúdo.

### Storytelling visual

Os capítulos foram organizados como uma sequência narrativa:

**dado → interpretação → exemplo → ação**

Cada tema apresenta primeiro o resultado, depois o contexto e, por fim, uma aplicação prática.

### Data storytelling

Os gráficos não aparecem de forma isolada.

Cada visual foi acompanhado de uma mensagem principal para ajudar o leitor a entender **o que aquele dado representa na prática**.

### Uso de cards

Indicadores importantes foram apresentados em cards para:

- destacar percentuais;
- comparar grupos;
- reduzir a carga de texto;
- melhorar a leitura rápida.

### Contraste e uso de cores

A identidade visual utiliza:

- fundo claro;
- cores de destaque;
- tons escuros para contraste;
- cores diferentes para facilitar comparações entre grupos.

As cores foram usadas com função informacional, e não apenas estética.

### Espaço em branco

O layout evita excesso de elementos.

O uso de espaço em branco ajuda a:

- separar blocos;
- criar ritmo visual;
- melhorar a legibilidade;
- direcionar a atenção para os principais insights.

### Tipografia editorial

Foi utilizada uma combinação de estilos tipográficos para criar contraste entre:

- títulos;
- textos explicativos;
- indicadores;
- frases de impacto.

Essa combinação reforça a aparência de publicação editorial.

### Ritmo de leitura

A estrutura foi pensada para funcionar como uma leitura rápida, semelhante ao consumo de conteúdo digital:

- frases curtas;
- poucos blocos por página;
- números grandes;
- gráficos simples;
- mensagens objetivas.

---

## 🧠 Estrutura dos capítulos

Cada capítulo segue uma lógica semelhante:

1. apresentação do resultado;
2. interpretação do dado;
3. cuidado metodológico;
4. exemplo prático;
5. recomendação de aplicação.

Essa estrutura foi utilizada para evitar que o ebook se tornasse apenas uma sequência de gráficos.

---

## ⚠️ Nota metodológica

A análise considera uma base de **32 participantes**.

Por isso, os resultados devem ser interpretados como **associações observadas dentro deste grupo**, e não como relações definitivas de causa e efeito.

Esse cuidado foi mantido ao longo do ebook para evitar conclusões mais fortes do que os dados permitem.
